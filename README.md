# Carlos Alcantara — Portfolio

Personal portfolio website built with plain HTML, CSS, and JavaScript. No build step required.

## Run locally

Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Structure

- `index.html` — page markup
- `style.css` — styles (dark/light themes)
- `index.js` — navigation, galleries, project modal, animations
- `assets/` — images, project screenshots, resume, certificates
